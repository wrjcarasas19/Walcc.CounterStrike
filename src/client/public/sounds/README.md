# Announcer sounds

Made for this project; no Unreal Tournament, Quake or other third-party game
sounds. Every file is generated by
[`plans/new-features-1006-tools/sounds/generate.sh`](../../../../plans/new-features-1006-tools/sounds/generate.sh)
(see "Regenerate" below). Vite copies this folder to `dist/sounds/`; the Go
server serves `.webm` as `audio/webm` and `.mp3` as `audio/mpeg`
(`src/server/static.go`).

Each sound is in two files: Opus in WebM (`.webm`, 48 kHz mono, 64 kb/s) and
MP3 (`.mp3`, 44.1 kHz mono, 64 kb/s CBR, no ID3 tag) for browsers without
Opus-in-WebM decoding (older Safari).

## How they are made

`make.sh`, step by step:

1. **Voice:** `piper -m en_US-john-medium.onnx --length-scale 1.05
   --noise-scale 0 --noise-w-scale 0` (noise 0: the same text always gives
   the same audio). Texts are in `make.sh`; some spellings were picked by
   transcribing the output with Whisper (`base.en`): e.g. "Quad kill" comes
   out as "quad to kill", so the text is "Quad-kill!".
2. **Announcer chain** (ffmpeg): trim silence, pitch 10 % lower
   (`asetrate`) and slightly slower, high-pass 80 Hz, +5 dB bass at 140 Hz,
   +3 dB at 3 kHz, compressor (5:1), then an echo (70/140/230 ms) for an
   arena feel.
3. **Jingles** (SoX `synth`, run with `-R` so it's repeatable): notes of a
   C major arpeggio; mixed under the voice with `amix` (voice delayed
   330–450 ms).
4. **Loudness:** measure EBU R128 integrated loudness (ffmpeg `ebur128`),
   gain to **-16 LUFS**, then `alimiter` at -2.5 dBFS run at 192 kHz (4×
   oversampled, so it limits true peaks), three passes.
5. **Encode:** `libopus -b:a 64k -application audio` into WebM, and
   `libmp3lame -b:a 64k` (44.1 kHz), both with `-map_metadata -1` and
   bitexact flags. (At 40 kb/s libopus came out ~1.5 LU quieter.)
6. **Check:** decode every file and measure it with `ebur128=peak=true`;
   fail if a file is ≥ 30 KB, above -1 dBTP or more than 1 LU from -16.

Output is deterministic: two runs give byte-identical files.

## Regenerate

Needs Docker and network (first run downloads the base image, Piper and the
63 MB voice).

```sh
plans/new-features-1006-tools/sounds/generate.sh
```

It builds `local/cs16-sounds`, runs `make.sh` in it with this folder
mounted at `/out`, overwrites the `.webm` / `.mp3` files and prints the
table above. To change a line, edit its text in `make.sh`; to add a sound,
add a `voice_line <name> "<text>"` line (or a stinger + `overlay`).
